# Asistente Virtual en Dialogflow

Proyecto de práctica de creación de un chatbot utilizando Dialogflow.  
Incluye un archivo `frases_chatbot.csv` con:  
- `ID`: identificador de cada frase.  
- `Frase de entrenamiento`: posibles formas en que un usuario puede preguntar o decir algo.  
- `Respuesta`: la respuesta que el chatbot debe dar.

💡 Objetivo: Mostrar habilidades en la preparación de datos para asistentes virtuales y manejo básico de Dialogflow.
